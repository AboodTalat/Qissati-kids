# Bundled CMYK profile

`Coated_Fogra39L_VIGC_300.icc` is the automatic fallback for Qissati's
PDF/X-4 printer export. It represents the FOGRA39 coated-art printing
condition with a 300% total area coverage limit.

Source: International Color Consortium profile registry
<https://registry.color.org/profile-registry/Coated_Fogra39L_VIGC_300>

Copyright: X-Rite, Inc. The registry states that VIGC makes the profile
available with permission from X-Rite and that it may be used, embedded,
exchanged, and shared without restriction. It must not be altered or sold
without written permission from VIGC. Keep the binary unmodified.

This is a production-structured standard fallback, not a calibration of a
specific press and stock. A printer-supplied output profile remains the more
accurate override.
